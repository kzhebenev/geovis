# Архитектура GeoVis

**[English version](../en/ARCHITECTURE.md)**

```
 первоисточники (GHSL, WorldPop, NASA, NOAA, Всемирный банк, Росстат, …)
        │  pipeline/prepare.py  (Python, uv, rasterio, geopandas)
        ▼
 web/public/data/  — сетки float32 (.bin + .json), catalog.json, границы, подписи, значения по странам
        │  vite build
        ▼
 ┌───────────── docker compose ─────────────────────────────────────────────┐
 │  geovis (nginx)      статика сайта + /data, прокси /api/ и /mcp → api      │
 │  api (FastAPI + MCP) свои наборы (контракт v1), ключи, снимки, видео        │
 │  renderer (Node)     headless Chromium + ffmpeg: PNG-снимки и MP4           │
 └────────────────────────────────────────────────────────────────────────────┘
```

## pipeline/ — подготовка данных

- `geovis_pipeline/catalog.py` — реестр всего, что есть на сайте:
  - `DATASETS` — сеточные наборы: URL источника, агрегация `sum`/`mean`, полоса, единицы, подсказки вида, лицензия;
  - `COUNTRY_DATASETS` — показатели Всемирного банка по странам;
  - `REGION_DATASETS` — статистика Росстата по субъектам;
  - `REGIONS` — страны-фокусы;
  - `LICENSES` — лицензии источников.
- `download.py` скачивает источник и распаковывает его, если нужно. Большие общие архивы кешируются.
- `grid.py` агрегирует растр в сетки 1° / 0,5° / 0,25° / 0,1° / 0,05°:
  - для наборов-сумм (население, CO₂) — точная поблочная сумма, итог сохраняется;
  - для «средних» (температура, рельеф) — среднее по площади.
- Для стран-фокусов строятся свои сетки с маской страны. Для Чукотки долготы разворачиваются через 180°.
- `country_stats.py` считает значение каждого набора по странам: среднее по площади, для показателей «на душу» —
  с весом по населению; итог для сумм. Эти значения идут в подписи стран.
- `admin1.py` строит границы регионов (Natural Earth admin-1), исправляет ошибки кодов и названий,
  разбирает таблицы Росстата. Несопоставленный регион — ошибка, а не тихий пропуск.
- `labels.py` готовит подписи стран и городов и упрощённые границы для подложки.

Подробнее — [DATA.md](DATA.md).

## web/ — сайт (React 19, Vite, deck.gl 9, Tailwind 4)

- `App.tsx` — сцена:
  - `ColumnLayer` для столбиков;
  - собственный меш поверхности (`surface.ts`) → `SimpleMeshLayer` со стенками;
  - `GeoJsonLayer` для 3D-картограмм стран и регионов;
  - глобус (`_GlobeView`) или карта (`MapView`).
- `scale.ts` — шкалы (лог/корень/линейная), палитры, расходящаяся шкала для разницы наборов.
- `smooth.ts` — сглаживание поверхности. `grid.ts` — выборка значения в точке.
- `Labels.tsx` + `placement.ts` — HTML-подписи с жадной раскладкой без наложений.
- `scenario.ts` — сценарии: `cameraAt`, `settingsAt` (плавные ключи `seriesYear`, `height`), `captionAt`.
  Чистые функции: один и тот же `t` даёт один и тот же кадр, на этом построена покадровая запись видео.
- `Panel.tsx` + `ui.tsx` — панель настроек: сегменты, выпадающие списки, тумблеры, окна.
- `urlstate.ts` — все параметры вида в URL, поэтому любую сцену можно отдать ссылкой или iframe.
- `csv.ts` — разбор CSV и вставки из Excel, распознавание стран и регионов по названиям и кодам.
- `window.__geovis` — хук для автотестов и рендера: `seek(t)`, `setSettings`, `ready`, `grid`, `visibleLabels()`.

## api/ — FastAPI + MCP

- `contract.py` — контракт данных v1 (Pydantic): `points` / `countries` / `regions` / `grid`, временные ряды, `ttl_days`.
- `process.py` переводит данные в сетку или значения по странам/регионам, сводит ряды по годам.
- `service.py` — хранилище наборов (`api-data/`), ключи (SQLite), лимиты, чтение встроенного каталога.
- `snapshot.py` — PNG-снимки через renderer, со строгим белым списком параметров. `preview.png` — для `og:image`.
- `mcp_server.py` — MCP-инструменты (streamable HTTP, без сессий, `X-API-Key`).

## renderer/ — снимки и видео

Node + puppeteer-core + Chromium из Debian (программный рендер SwiftShader) + ffmpeg.

- `/render` открывает сайт с `render=1`: без анимаций, с упрощёнными границами.
- Ждёт `__geovis.ready` и снимает PNG. Кеш учитывает отпечаток сайта (ETag страницы и каталога).
- `/video` проходит сценарий покадрово через `seek(t)` и собирает H.264 MP4. Задачи идут через очередь.

## nginx

`nginx.conf.template` (envsubst):

- статика с кешированием;
- `/data` — сетки с правильными MIME-типами;
- прокси `/api/` и `/mcp` на `GEOVIS_API_UPSTREAM`;
- подстановка `og:image` в HTML по параметрам ссылки, разрешены только безопасные символы.

## Тесты

- `pipeline/tests` — «правда о мире»:
  - население Земли ≈ 8 млрд;
  - пик России — Москва;
  - сумма ВРП регионов = ВРП России;
  - ВВП на душу по странам ≈ данным Всемирного банка;
  - негативные кейсы.
- `web/src/*.test.ts` (vitest) — шкалы, сетки, сценарии, CSV, подписи.
- `api/tests` — API и MCP через настоящий JSON-RPC.
- `web/e2e/*.mjs` — сцена, интерфейс, сценарии, API и аудит подписей по всем наборам в headless Chrome:
  проверяется видимый результат и отсутствие JS-ошибок.
