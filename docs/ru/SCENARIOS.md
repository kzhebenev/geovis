# Сценарии полёта камеры GeoVis

**[English version](../en/SCENARIOS.md)**

Та же справка — на сайте: блок «Сценарий полёта» → кнопка «?».

## Быстро, без JSON
Камера мышью (левая — сдвиг, правая или Ctrl — наклон и поворот, колесо — приближение), выберите набор и вид →
**«+ Кадр»**. Повторите для следующих ракурсов (каждый новый кадр — через 5 с). ▶ — проиграть.
Чтобы поправить время или добавить титры: кнопка ⤓ «Скачать сценарий» → правка JSON → ⤒ «Загрузить сценарий». Готовый сценарий → **«Видео»** (MP4).

## Ключевой кадр
| Поле | Смысл |
|---|---|
| `t` | секунда, когда камера приходит в ракурс (по возрастанию) |
| `camera.longitude/latitude` | точка, **на которую смотрит** камера (облёт — та же точка, меняется `bearing`) |
| `camera.zoom` | 1 — Земля, 2–3 — континент/большая страна, 4–5 — регион, 6–7 — город |
| `camera.pitch` | 0 — сверху, 45–65 — «пролёт», до 85 — у горизонта |
| `camera.bearing` | 0 — север вверху, 90 — смотрим на восток |
| `easing` | как летим **к** кадру: `inOutCubic` (по умолчанию), `linear` (облёт), `inOutSine`, `outCubic` |
| `arc` | дальние перелёты (> 25°) идут по дуге; `false` — отключить |
| `settings` | смена сцены в момент кадра: `dataset`, `countryDataset`, `year`, `focus`, `mode`, `theme`, `projection`, `palette`, `scale`, `smooth`, `height`, `res`, `cityMinPop`, `cityLimit`, `numbers`, `showLegend`, `lang` |
| `caption` | титр `{"ru": "…", "en": "…"}`, проявляется 0,6 с; `null` — убрать |
| `settings.seriesYear` | **плавный год** серии (население 1975…2100): между кадрами интерполируется, столбики растут непрерывно |
| `settings.compareWith` | **разница**: текущий набор минус этот (`"pop1975"`, `"temp"`); `null` — выключить |

## Плавный рост и разница
```json
{"t": 0,  "camera": {...}, "settings": {"dataset": "pop1975", "seriesYear": 1975}},
{"t": 20, "camera": {...}, "settings": {"seriesYear": 2025}},
{"t": 35, "camera": {...}, "settings": {"seriesYear": 2100}, "caption": {"ru": "2100 — прогноз"}}
```
Год меняется непрерывно, как камера. Для «что изменилось» — `{"dataset": "pop2025", "compareWith": "pop1975"}`:
рост красным, убыль синим, высота — величина изменения.

## Советы
3–6 с на перелёт, 6–10 с на облёт; сначала общий план, потом «нырок». Перед сменой набора — 1–2 с паузы.
Кадр в момент t детерминирован: что видно на шкале времени, то и попадёт в видео.

## Видео (MP4)
Кнопка «Видео» или API: `POST /api/v1/videos {"scenario": {...}, "fps": 24|25|30, "quality": "720p"|"1080p"|"720p_v"|"1080p_v"}` →
`{id}`; прогресс — `GET /api/v1/videos/{id}` (`state`, `frame/frames`, `eta_s`); файл — `GET /api/v1/videos/{id}.mp4`.
До 180 с; очередь — одна задача в работе и до трёх в ожидании (иначе 429); файлы хранятся 7 дней.
Рендер без видеокарты: ~1 с на кадр в 720p (30 с при 30 к/с ≈ 15 мин), 1080p — примерно вдвое дольше.
