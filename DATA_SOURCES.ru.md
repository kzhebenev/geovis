# Источники данных и лицензии

**[English version](DATA_SOURCES.md)**

**В этом репозитории нет географических данных.** Пайплайн (`pipeline/prepare.py`) сам скачивает каждый набор
у первоисточника и превращает его в сетки для сайта. Лицензия MIT этого репозитория распространяется **только на
код и документацию**. Данные остаются под лицензиями их издателей. Соблюдать их обязан тот, кто запускает
пайплайн и публикует получившийся сайт.

Лицензии ниже проверены по страницам самих издателей **09.10.2026**. Условия меняются, поэтому перед коммерческим
использованием перепроверьте их. Этот документ — не юридическая консультация.

## Кратко

| Статус | Наборы |
|---|---|
| ✅ Свободно, в том числе коммерчески, **с указанием источника** | население 1975–2030 (GHSL), прогноз населения 2040–2100 (WorldPop), застройка 2020 (GHSL), морские пути (Всемирный банк), сетки ВВП (Kummu et al.), ВВП стран (Всемирный банк), регионы России (Росстат) |
| ✅ Общественное достояние / не охраняется авторским правом (ссылка желательна) | границы стран и города (Natural Earth), рельеф (NOAA ETOPO 2022), ночные огни (NASA Black Marble) |
| ⚠️ **С ограничениями**: только некоммерческое использование и/или запрет распространения производных данных | климат 1970–2000 / 2041–2060 / 2081–2100 (WorldClim 2.1), выбросы CO₂ (IEA-EDGAR CO₂) |

**Наборы с ограничениями по умолчанию выключены**: `prepare.py` пропускает их без флага `--include-restricted`.
Включайте флаг, только если ваше использование укладывается в их условия (например, закрытая некоммерческая
установка) или у вас есть разрешение издателя. Публичный сайт, который отдаёт производные сетки, — это
**распространение** данных. В окне выбора данных такие наборы помечены «некоммерч.».

## Обязательные ссылки

Показываются в приложении под каждой картой (строка «Данные:»), полный текст — в `catalog.json` → `datasets[].license.cite`.
Формулировки — в [английской версии](DATA_SOURCES.md#required-citations) (ссылки на наборы даются на языке издателя).

## Как GeoVis соблюдает указание авторства

- На каждой карте внизу строка «Данные: …» с источником (`catalog.json` → `source`). Она лежит на подложке и читается
  поверх любых данных. Видео и PNG-снимки рисуют ту же строку.
- В `catalog.json` у каждого набора есть объект `license`: `id`, `name`, `url`, `restricted`, `cite`.
- В окне выбора данных наборы с ограничениями помечены «некоммерч.», во всплывающей подсказке — лицензия и цитата.
- Свои данные, загруженные через API или CSV, принадлежат вам. Заполните поле `source`, и оно появится под картой.
